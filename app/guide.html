从零开始，5 步用起来

适用于 Windows 10 / 11。全程只需配置一次，之后每天开播双击一个文件即可。

开源申明：本软件完全开源，无任何额外付费功能或授权限制。使用中请遵守抖音平台规则：软件只读取公开弹幕，不会用你的账号发弹幕、送礼或关注任何人。
0

环境准备（只做一次）

  • 安装 Python 3（官网下载，安装时勾选 Add to PATH），然后命令行执行 pip install pywebview
  • WebView2 Runtime：Windows 11 自带；Win10 若缺失，去微软官网装一次
  • 安装 Node.js（官网 LTS 安装包，一直下一步即可）
  • 把软件文件夹放到任意位置，例如 D:\SU\310\5
1

一键启动

  • 双击 start-all.bat：自动启动打印服务 + 弹出「直播间窗口」+ 打开「头像打印程序」，两个窗口并排
  • 也可以分开启动：start.bat（打印服务）+ start-bridge.bat（数据桥）
  • 想固定房间号启动：命令行执行 pythonw launch.py --room 房间号 --capture，开播即自动抓取
2

登录抖音（只需一次）

  • 在弹出的「直播间窗口」里扫码/验证登录抖音，登录状态会记住，下次免登录
  • 登录后头像抓取更全：可以抓到更完整的观众资料卡头像
3

连接直播间，开始抓取

  • 在打印程序右侧「直播连接」面板填直播间号或整条链接，回车或点「切换」
  • 点「开始抓取」，抓取状态显示 ● 正常 · 弹幕… 即成功
  • 右上角亮起「● 直播数据 · 数据桥已连接 · 房间号」
4

看打印效果

  • 观众评论 / 点赞 / 送礼 → 打印机自动打印 TA 的头像：逐层打印 → 出分 → 机械臂转运到传送带
  • 连续 30 秒没人说话时，会自动补一张测试头像让画面不冷场；真实消息一到立刻恢复真人优先
  • 右侧面板可看打印队列、打印记录（昵称/头像/触发方式/分数/时间）
5

用到直播画面里

  • 打印画面点「弹出直播窗口」，得到 1080×1920 竖屏独立窗口
  • OBS 里添加「窗口采集」，选中这个竖屏窗口，即可作为直播间画面源
  • 想展示全景控制台，直接采集打印程序主窗口也可以

常用操作 TIPS

视角与镜头

画面里按住拖动即可转动视角；「＋保存当前视角」最多存 10 个命名镜头；随手拖动的机位会自动记忆，刷新不丢；「初始视角」一键回位。

画质与状态牌

画质四档：标准 / 2×精细 / 4×超清 / 8×影院，选择自动记忆；「状态牌」按钮可显示/隐藏画面上的打印状态牌。

暂停 / 跳过 / 速度

「暂停打印」同时冻结打印和流水线；「跳过当前」只丢弃正在打印的这件；演示速度 1× / 4× / 12× 可加速验收。

切换直播间

在「直播连接」面板填新房间号或链接回车即可，数据桥自动切换并记住；无需重启程序。

批量导入头像

规则演示台里「批量导入头像」可选本地图片，替换演示头像池，仅本机使用不上传。

关闭程序

直接关闭打印程序主窗口即可：程序会自动停止抓取、清理数据桥和它打开的直播窗口。

常见问题 FAQ

双击后页面打不开 / 提示 8080 被占用？

说明打印服务端口被其他程序占用。关掉占用 8080 的程序（或重启电脑）后再双击 start-all.bat。

点「开始抓取」提示端口 8765 被占用？

有旧的数据桥还在运行。按提示关闭旧版 ServerGuard / BridgeGuard / 旧数据桥窗口，再重新开始抓取。

抓取状态一直是「等待直播动态」？

直播间窗口还没登录或没进入直播间。先在直播窗口完成登录并进入房间，再点开始抓取。

有些观众显示彩色首字而不是照片头像？

TA 的头像暂时没抓到（比如已滚出屏幕）。软件会自动多轮点击资料卡补取，观众多发几条评论通常就能抓到真实头像。

30 秒没人说话，打印机还在打印？

这是「冷场保护」：自动补测试头像让画面不空转。有真实观众消息时立刻恢复真人优先，测试头像自动让位。

没有声音？

浏览器策略要求先有交互：点击页面任意位置即可；桌面版窗口默认允许声音。检查系统音量与输出设备。

分数是真实的吗？

不是。评分为 60–95 的娱乐随机分，不同分数段对应不同打印材质（胡桃木/拉丝铝/石材/陶瓷等），仅作直播互动效果。

会被抖音封号吗？

软件只读取直播间公开弹幕与公开头像，不登录、不发弹幕、不点赞、不送礼，不做任何写操作，与观众自己观看直播无异。请勿将其用于任何违法违规用途。
