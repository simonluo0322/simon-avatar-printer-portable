# v2.0.0 直播功能大版本

## 🎯 头像抓取：实时评论 100% 带头像
- 修复协议级解码三处根因（信封误杀 / 昵称张冠李戴 / 事件广播未定义），评论者头像直接从直播协议流读取，零点击零延迟

- 主窗口照常运行不受影响；多窗口自动选举，**绝不重复打印**
